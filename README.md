# Neighborhood Listing Platform

A simple Next.js platform for discovering neighborhood properties, connecting with local sponsors, and accessing helpful information through voice assistance.

## Project Purpose

The Neighborhood Listing Platform provides an accessible and easy-to-use starting point for neighborhood property information.

## Current Features

- **Listings** — Browse neighborhood property listings and information.
- **Neighborhood Sponsors** — Discover local businesses and organizations.
- **Voice Help** — Provide accessible voice assistance.

## Technology Stack

- Next.js
- TypeScript
- Tailwind CSS
- ESLint
- Next.js App Router

## Local Development

Install dependencies:

```bash
npm install
```
